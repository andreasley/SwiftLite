**Model**

A `class` annontated with `@Model` that defines the schema for SQLite persistence. Properties are automatically mapped to columns.

**Model object *or* Object**

An instance of some `Model`.

**Snapshot**

An read-only, `Sendable` representation of some data from the database.

**Default Snapshot**

A Snapshot of the first layer of a Model (usually a single row in the database); automatically generated by the `@Model` macro.
